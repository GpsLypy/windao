# WinDao 组件清单

打开工作台的「插件集市」，选择「导入本地 JSON」，预览内容后点击「安装」。同一页可安装随包的开工检查清单和 Windows 常用入口，也可以点击「刷新在线目录」，查看 WinDao GitHub 仓库提供的组件。

下面是一份清单组件。以 UTF-8 保存为 `checklist.json`。组件 ID 用于识别同一份组件，建议为自己创建的组件使用独有 ID。

```json
{
  "version": 1,
  "id": "example.before-leaving",
  "title": "离开办公室前",
  "widget": {
    "type": "checklist",
    "items": ["备份工作资料", "确认明天的日程"]
  }
}
```

- `version` 必须为整数 `1`。文件上限为 16 KiB，所有对象均只接受列出的字段。
- `id` 以小写英文字母开头，最多 64 个 ASCII 字符，可使用小写字母、数字、点、连字符和下划线。`bundled.` 和 `catalog.` 用于 WinDao 提供的组件。
- `title` 最多 48 字符。`widget` 有三种类型。
  - `text` 接受一个 `body` 字符串，最多 1500 字符，可用换行。
  - `checklist` 的 `items` 接受 1 至 10 条文本，每条最多 96 字符。
  - `links` 的 `items` 接受 1 至 10 个对象，每个对象由 `title` 和 `url` 组成。标题最多 64 字符。网址最长 512 字节，须为无登录凭据的 HTTPS 网址。点击链接会用默认浏览器打开。
- 文本必须包含可见内容。除正文换行外，字段禁止控制字符。

首次安装会启用组件。停用或移除后仍保留状态及已勾选项目，可在「我的组件」恢复。重复导入相同组件也可恢复。相同 ID 与内容绑定，修改清单后可换用新 ID。移除后可以确认永久清除该组件及其数据。组件库最多保留 24 个条目，包括已移除条目。

组件库保存在 WinDao 本机资料目录中的 `widgets.json`。组件由 WinDao 按固定格式渲染，支持显示文本、勾选清单，以及点击后打开 HTTPS 链接。
