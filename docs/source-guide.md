# NotchCalendar 使用指南

## 胶囊和工作台

从托盘打开工作台或设置。按 Ctrl+Shift+Space 展开胶囊。在工作台中用 Ctrl+Tab 和 Ctrl+Shift+Tab 切换页面。在「设置」调整停靠边、显示器、大小、时钟、透明度和页面顺序，或为浏览器和指定程序开启避让。按住 Ctrl 拖动收起的胶囊可换边或跨屏。「在截图和录屏中隐藏胶囊」默认关闭，效果取决于捕获工具对 Windows 窗口排除机制的支持。

## 音乐、日历和提醒

- 音乐页读取当前系统媒体会话。可为曲目导入本地 LRC，或主动向 LRCLIB 查询曲名、歌手、专辑和时长。
- 「日历」显示选中日的农历与节气。置于日期上可查看对应日期的农历信息。「日历来源」支持 HTTPS ICS 订阅和 CalDAV。需要认证时，请按日历服务商要求填写用户名与应用专用密码。同步失败时保留上次成功结果。CalDAV 日程只读。
- 重复待办可以按星期完成。启用提醒后，日程、待办和专注计时结束会请求 Windows 显示提示。工作台「通知」保存最近 100 条已发出的提醒，可手动清空。
- 「通知 → 第三方任务栏提示」默认关闭。开启后记录微信、企业微信、飞书和钉钉的任务栏闪烁，记录包含来源和时间，可单独清空。
- 「专注」里的饮水和久坐提醒可分别启停，间隔为 5–240 分钟。可手动记录当天饮水次数，记录按本机日期更新。
- 「系统性能」显示 CPU、内存和网速，也可查看不同时区的时间。

## 桌面工具

- 「我的日子」可存储纪念日、截止日期等日期，并显示距今天的天数。
- 工具页可手动从 Gold API 查询 XAU 美元现货报价。以界面上的来源时间为准。
- 工具页的实时工资按本机时间、周一至周五、用户设置的日薪、起止工时和休息时段估算。设置单独保存在本机。
- 启用剪贴板历史后，NotchCalendar 仅在内存中保留本次运行最新的 30 条文本。可逐条移除或清空，退出即清空。
- 「天气」通过 Open-Meteo 按城市名称查询实况与七日预报。搜索时发送填写的城市名，查看天气时使用所选城市坐标。
- 「无线设备」列出 Windows 已配对的蓝牙设备。支持标准电量服务的低功耗蓝牙设备可手动读取电量。
- 「插件集市」提供随包组件、手动刷新的 NotchCalendar 在线目录和本地 JSON 导入。组件可停用、移除或恢复，独立保存的清单进度随组件保留。[组件格式说明](widget-manifest.md)

## 本机数据与迁移

工作区位于 `%APPDATA%\WinDao`。卸载保留数据。日历订阅地址与 CalDAV 凭据通过 Windows 数据保护保存，备份不携带凭据，包含工作区内容及通知历史。

首次从旧版 Electron Windows 客户端迁移时，可在空工作区打开「设置 → 导入旧版数据」。NotchCalendar 读取旧工作区提供的日程、待办、专注、便笺、卡片和会议笔记。已有 Rust 预览版用户可以先从旧版导出工作区备份，再在 NotchCalendar 的设置中恢复。恢复后在「日历来源」重新连接。

## 预览验证

用自动化测试检查存储、停靠计算和界面。Windows 实机的多屏 DPI、窗口避让、媒体会话、录屏隐藏和安装流程仍需验收。
