# NotchCalendar 使用指南

## 胶囊和工作台

从托盘打开工作台或设置。按 Ctrl+Shift+Space 展开胶囊，先看日历。点标题旁的「功能菜单」切换到待办、文件等页面。在胶囊菜单点「退出应用」或在工作台点「退出 NotchCalendar」，即可关闭整个程序。在工作台中用 Ctrl+Tab 和 Ctrl+Shift+Tab 切换页面。在「设置」调整停靠边、显示器、大小、时钟、透明度和页面顺序，或为浏览器和指定程序开启避让。按住 Ctrl 拖动收起的胶囊可换边或跨屏。「在截图和录屏中隐藏胶囊」默认关闭，效果取决于捕获工具对 Windows 窗口排除机制的支持。

## 音乐、日历和提醒

- 在「音乐」选择可用的 Windows 媒体会话，可切歌、控制播放、拖动进度并调整该应用音量。具体按钮取决于播放器上报的能力。歌词支持导入 LRC、用曲名和歌手查询 LRCLIB，也可搜索网易云目录或填写歌曲 ID。
- 在「日历 → 日历来源」连接 HTTPS ICS、CalDAV 或 Exchange ActiveSync。可从飞书、钉钉、企业微信、iCloud 预设开始，填写服务商提供的同步地址及凭据。列表里只显示去重后的会议和各次重复实例，同步失败时保留缓存。日历可以设置会议提前提醒，也能离线查看农历和节气。
- 在功能菜单或托盘打开「桌面待办」，输入标题后按 Enter 添加，勾选即可完成。刘海、桌面和工作台共用同一份待办。点任务旁的「•••」编辑、暂缓、取消或恢复。底栏可设置分类、优先级、截止时间、标签和备注。顶栏可切换四象限、日历和统计，点铃铛可设置未完成待办的定时汇总。重复任务在下一次到期时恢复待办状态。
- 「通知」保存最近 100 条应用提醒。开启第三方任务栏提示可按窗口查看微信、QQ、企业微信、飞书和钉钉的闪烁提醒。点击未读角标进入通知，再选择来源窗口。带包身份的 MSIX 经用户授权后可读取 QQ 系统通知，正文预览另行开启。
- 「专注」支持专注与休息计时、饮水和久坐提醒。可设每日饮水目标、每杯容量、起止时段和午休，记录错误可撤销。

## 胶囊菜单

展开日历，点击标题旁的菜单，可在三列中搜索并打开工具。

- **AI 工作台**。在「对话」或「智能助理」输入本次会话使用的 DeepSeek Key。点击发送后内容交给 DeepSeek。助理提出待办后，可确认保存到本机清单。
- **翻译**。安装并启动 Ollama，再在翻译页面下载约 1 GB 的 qwen2.5:1.5b 模型。模型准备好后，翻译请求发往本机。译文可以复制，源语言和目标语言可以互换。
- **截屏与录屏**。用系统截图工具选区、标注和保存。Windows 11 的新版截图工具支持区域录屏，Windows 10 和 11 也可以在 Game Bar 录制应用并打开捕获文件夹。
- **身份验证器**。可从二维码图片、otpauth URI 或手动输入创建 TOTP。选用 Windows Hello 或独立口令解锁，密钥由当前 Windows 用户加密保管。离开页面会锁定保险库。
- **开发工具**。选择 JSON、时间戳、UUID、二维码、命名转换、图片压缩、Base64 或 URL 编解码，输入内容后可查看、复制或保存相应结果。
- **行情**。可手动刷新全球股指和汇率，按代码、名称或拼音查找沪深 A 股、管理自选，并查看现货金价。

## 邮箱

在「邮箱」添加已开通 IMAP 的账户。预设包括 QQ、163、126、腾讯企业邮、iCloud 和 Gmail，自定义服务支持 TLS 主机及端口。保存后可刷新最近 30 封，点开邮件可读正文、复制验证码、在独立窗口阅读全文或预览并导入日历邀请。验证码可选择 30、60、300 秒后自动隐藏。在「账户管理」可以为此邮箱开启服务器已读和移动同步，默认只在本机整理。

## AI 用量

「AI 用量」有本机使用记录和服务商账户两部分。本机记录按本地日期统计今天和最近七天，缺少记录时会显示原因。服务商账户支持命名、配色和固定到横向胶囊，每次读数附有来源时间。固定账户按五分钟间隔刷新，文件来源显示对应记录的时间。

| 账户 | 首次连接 |
| --- | --- |
| Codex | 添加本机账户并选择含 sessions 的 Codex 数据目录，可为不同工作配置选不同目录。订阅窗口和 token 使用记录来自该目录 |
| Claude | 在桌面版打开用量页面后选择 plan-usage-history.json，或在 Claude Code 账户中连接官方状态栏。已有自定义状态栏时可复制命令自行组合 |
| DeepSeek、Kimi API、Kimi Code、GLM Coding Plan | 按服务及地区建账户。API 余额使用该账户的 API Key，订阅窗口使用对应套餐凭据 |
| Antigravity CLI | 连接官方状态栏或选择自己的用量 JSON，查看模型、剩余额度及重置时间 |
| WorkBuddy | 在账户中点浏览器授权，完成后回到应用查看剩余积分 |
| Kiro | 按美国东部或欧洲中部建立账户，填写已授权的访问令牌。过期后重新连接 |
| Gemini、Grok Bot | 点击「准备浏览器用量分享工具」，在 Chrome 或 Edge 扩展管理中加载打开的文件夹。在官方用量页面分享数据并选择对应账户文件 |
| 中转站 | 填站点 HTTPS 地址和 Key，常见接口会自动识别。New API 用户 Token 还需用户 ID。自定义接口可填写完整 HTTPS 地址、JSON 字段路径和单位。也可导入 CC Switch 通用、New API、Sub2API 模板，以及只含同站 GET 与数值运算的受支持配置 |


### 导入 CC Switch 中转站配置

在「AI 用量 → 添加账户 → 中转站 → 导入 CC Switch 用量配置」选择一个 JSON 文件，或粘贴脚本。支持单个 `usage_script` 对象、含 `usage_script` 的对象及服务商的 `meta.usage_script`。脚本可用配置中的 `baseUrl`，也可在账户地址栏填写站点。保存后请核对显示的完整查询地址，再输入此账户的 API Key 或访问令牌。勾选加密保存后，查询成功时 Windows 会为当前用户保存凭据。

- 通用、New API 和 Sub2API 支持官方模板。New API 读取用户 ID 和账户 Token，按模板换算余额、已用量和总额。Sub2API 支持带或不带 `/v1` 的站点地址，返回无限额订阅时显示套餐名称。
- 自定义请求支持同源 HTTPS GET，地址可使用 `{{baseUrl}}` 或完整地址。凭据占位符支持 Authorization 的 Bearer 或直接值、X-Api-Key 的 `{{apiKey}}`，以及 New-Api-User 的 `{{userId}}`。Authorization 可使用 `{{apiKey}}` 或 `{{accessToken}}`。配置内的账户密钥不会被导入。
- 自定义提取函数可直接返回 `remaining`、固定字符串 `unit` 和可选的 `used`、`total`、布尔字段 `isValid`。数值可从 `response` 读取嵌套字段与数组下标，并用括号和四则运算换算，例如 `(response.data.limit - response.data.used) / 100`。
- 每个配置最多 32 KiB。仅接受一个查询请求，查询参数、跳转、自定义函数调用和通用 JavaScript 控制流均不支持。账户固定后遵循胶囊的五分钟刷新周期。

## 桌面工具

- 「文件」支持拖入、打开、定位及拖出。剪贴板历史需要主动开启，最多保留 30 条文字，可固定、再次复制或清空。Windows 按当前用户加密保存，退出再打开仍可读取。
- 「天气」提供 Open-Meteo 实况与七日预报，可搜索城市或主动按网络位置定位。使用和风天气时填写自己的 Host 和 Key。可收藏城市、查看请求预算，在没有网络时查看已有预报。
- 「系统性能」可查看 CPU、内存、网速与世界时钟。可选开启电源、网络、音量、输入及蓝牙状态提示。「无线设备」可读取支持标准电量服务的已配对设备。
- 「我的日子」记录纪念日和截止日期。「行情」可手动刷新美元现货金价。「工时收入」按本机日期和设定工时计算。
- 「插件集市」支持随包组件、目录更新与本地 JSON 安装，升级时保留匹配的勾选项。[组件格式说明](widget-manifest.md)

## 本机数据与迁移

工作区位于 `%APPDATA%\WinDao`。卸载保留数据。日历订阅地址与 同步凭据通过 Windows 数据保护保存，备份不携带凭据，包含工作区内容及通知历史。

首次从旧版 Electron Windows 客户端迁移时，可在空工作区打开「设置 → 数据与备份 → 导入旧版工作区」。NotchCalendar 读取旧工作区提供的日程、待办、专注、便笺、卡片和会议笔记。已有 Rust 预览版用户可以先从旧版导出工作区备份，再在 NotchCalendar 的设置中恢复。恢复后在「日历来源」重新连接。

## 预览验证

在「设置 → 关于」可检查更新、校验后安装，或导出诊断 ZIP。Windows 实机的多屏 DPI、窗口避让、媒体会话、录屏隐藏和安装流程仍需验收。
