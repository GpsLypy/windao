## Why

Publish the Windows Rust desktop capsule as an independent open-source project and close several interaction gaps identified in the Daozai v0.6.70 implementation.

## What Changes

- Publish a standalone WinDao source tree, MIT license, product documentation and Windows x64 packages.
- Add bottom docking, cross-monitor movement and optional Windows capsule capture exclusion.
- Add system performance, world clocks, local notification history, expanded synchronized lyrics and calendar time selection.
- Add important-date countdowns, XAU quotes, an on-device workday earnings estimate and optional text clipboard history.
- Add offline lunar dates and solar terms, a translucent capsule option, and keyboard navigation for workbench pages.
- Add city forecasts, paired Bluetooth device information, health reminders and a first-party widget catalog with local JSON imports.
- Add opt-in local history for signed chat apps' Windows taskbar flashes.

## Capabilities

### New Capabilities

- `windao` provides installable Windows desktop features from an open-source Rust repository.

## Impact

Windows packaging, workspace preferences and the Rust workbench are affected.
