Noto Sans SC Regular is the fallback for Chinese text on systems without Microsoft YaHei. The subset includes GB2312 and the workbench labels. The app uses the system fonts first.

The original font is [Noto Sans SC from Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans+SC), version 41 as served by Google Fonts. This TrueType file was subset using HarfBuzz and is licensed under the accompanying SIL Open Font License.
